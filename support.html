Troubleshooting and Support

First step for almost everything

Run Verify Install (the window's Verify section, or Tools > ByteLura > MiniAtlas Pro > Verify Install). Its five lines check the runtime assembly, exercise a map in memory (projection center, fog reveal, fog save/load round-trip), and confirm settings, sample and documentation are present. If a line fails, its wording is the diagnosis.

Common questions

The window says "No map settings yet." Setup has not run in this project. Click Run Setup — it creates the settings asset and starter art, and never touches your scene.

My map looks stretched. The background aspect and the bounds aspect disagree. The window's Map Setup section prints both numbers and says so in plain words. Resize the image, or re-fit the bounds with Fit Bounds to Selected.

A marker does not appear on the map. Work through its rule: When Explored and When Visible markers stay hidden while their fog cell is unexplored; Manual markers stay hidden until Reveal() is called. Then check the category's per-view flags — a category can be off on the minimap and on on the world map, or the reverse. An unknown category id is never the cause: it falls back to the default category.

The world map shows places I have not visited. It cannot — both views share the same rule evaluation. What you are seeing is explored fog: a place reads explored once any revealer's radius has covered its cell, even briefly. That is the designed meaning of Explored.

Fog from an old save will not load. The load is refused when the grid shape or cell size differs from the current map's fog — by design, and the grid is left untouched. Rebuild the map with the settings the data was saved under, or start the fog fresh for the new resolution.

The objective arrow is missing. The arrow shows only while an objective is tracked (MiniAtlasApi.SetObjective) and off-view, and only when the minimap's ShowObjectiveArrow is on. Once the objective enters the minimap's view, the arrow hides and the objective's own icon shows — that hand-off is the design.

The Atlas Tour scene did not open. The sample's code may still be compiling after import; the window retries on its own once the editor settles. If it still has not opened, use the sample's own menu item: Tools > ByteLura > MiniAtlas Pro > Build Atlas Tour Scene.
