Fog of War

Fog in MiniAtlas Pro is a data grid over the map bounds — not a shader trick and not a rendered picture. The grid size derives from the bounds and the cell size you set (clamped to 8..512 cells per axis). With the starter settings (100×100 bounds, cell size 2) that is a 50×50 grid; the Atlas Tour runs 48×32.

The three states

Every cell is in exactly one state:

  • Unexplored — never seen. Full fog on the map.
  • Explored — seen before, not currently watched. Dimmed fog.
  • Visible — inside a revealer's radius right now. No fog.

How it moves

Markers flagged Reveals Fog (typically the player) stamp a circular reveal each fog tick (every 0.1 s): cells in radius become Visible + Explored; cells outside every radius keep Explored but lose Visible. Reveals also stamp immediately on tick boundaries only — there is no per-frame fog work.

The map renders the grid as one generated texture on a RawImage above the background and below the icons: one texel per cell, updated only when a reveal or a tick changed something.

Fog never lies about markers

A marker whose visibility rule is When Explored or When Visible is hidden while its cell is unexplored — on the minimap and the world map, with no per-view exceptions. The player marker (rule Always) is the single documented exception class. The full rule table is in Markers and Categories.

Turning fog off

Set Fog Enabled off in the settings and the map runs without a fog grid: fog-based visibility rules then read visible. Some games want a map that is simply always known — that is a settings toggle, not a different product.

Saving

Explored state is the save data; visibility is derived and re-stamps on the next tick after a load. The byte and Base64 forms, the format, and the shape rules are in Saving Fog State.
