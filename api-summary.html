API Summary

The public surface of ByteLura.MiniAtlas. The full reference ships in the package (Documentation~/ApiReference.md); this is the short map of it.

The map

  • MiniAtlasMap (component) — owns a map: Settings, Projection, Fog, HasFog, RebuildFromSettings(), TickFog(), FogChanged event. MiniAtlasRuntime.ActiveMap is the currently enabled map; MiniAtlasRuntime.Registry is the shared marker registry.
  • MapSettings (ScriptableObject) — BoundsCenter, BoundsSize, Plane (XZ / XY), Background, FogEnabled, FogCellSize, FogExploredAlpha, FogColor, Categories, DefaultCategoryId; CreateProjection(), CreateFog(), GetCategory(id) (never null).
  • MapProjection — WorldToNormalized (unclamped), WorldToNormalizedClamped, NormalizedToWorld, Contains, Aspect.

Markers

  • MapMarker (component) — CategoryId, Label, VisibilityRule (Always / WhenExplored / WhenVisible / Manual), RevealsFog + RevealRadius, TrackHeading, Reveal(), IsObjective, Changed event. Registers on enable, unregisters on disable.
  • MarkerRuleEvaluator.IsVisible(marker, fog) — the shared rule evaluation both views use; a null fog reads fog rules visible.

Quest hooks — MiniAtlasApi

  • SetObjective(marker) / ClearObjective() / TrackedObjective
  • RevealMarker(marker)
  • Events: MarkerDiscovered (exactly once per marker), MarkerSelected, ObjectiveChanged
  • TryFindMarker(categoryId, out marker)

Fog — FogOfWar (via map.Fog)

  • Reveal(worldCenter, radius), GetState / GetStateAtWorld (Unexplored / Explored / Visible), IsExploredAtWorld, IsVisibleAtWorld, ExploredCount, GridWidth, GridHeight, CellSize
  • Save/load: SaveExplored() / TryLoadExplored(bytes), SaveExploredBase64() / TryLoadExploredBase64(text) — see Saving Fog State.

Views

  • MinimapView — FollowTarget, RotationMode (NorthUp / PlayerUp), Shape (Rectangle / Circle), Zoom / MinZoom / MaxZoom, ShowObjectiveArrow, SetZoom(value), RefreshNow().
  • WorldMapView — OpenKey (default M, None disables), Open() / Close() / Toggle(), IsOpen, CenterOnPlayer(), Zoom, ViewOffset.
  • Icons — pooled per view (MarkerIconPool.TotalCreated); membership follows the registry, the category flags, and the fog rules. You never manage icons directly.

Editor surface — ByteLura.MiniAtlas.Editor

  • MiniAtlasSetup — RunSetup(), VerifyInstall(out allPassed) (5 plain-language checks), AddMapToScene(), FitBoundsToSelected(settings), BackgroundAspectNote(settings), OpenAtlasTour(), FindSettings().
  • MiniAtlasWindow — the home window at Tools > ByteLura > MiniAtlas Pro.
