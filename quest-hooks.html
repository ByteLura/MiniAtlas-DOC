Quest Hooks — MiniAtlasApi

The marker API is the surface a quest system — yours, or any quest asset — drives. Everything is static, in ByteLura.MiniAtlas, and needs no reference to any other product.

Track an objective

MiniAtlasApi.SetObjective(marker);
MiniAtlasApi.ClearObjective();
MapMarker current = MiniAtlasApi.TrackedObjective; // or null

A tracked objective gets its category's styled icon, and while it is off-view the minimap shows it as an edge arrow at the border. The Atlas Tour sets its objective exactly this way at start.

Reveal a secret

MiniAtlasApi.RevealMarker(marker); // same as marker.Reveal()

Reveals a Manual-rule marker: it appears on both views and stays revealed. The tour's HUD button and its completion both call this.

Listen

MiniAtlasApi.MarkerDiscovered += m => { }; // first fog tick that explores a gated marker's cell — exactly once per marker
MiniAtlasApi.MarkerSelected   += m => { }; // clicked on the world map
MiniAtlasApi.ObjectiveChanged += m => { }; // the tracked objective changed

MarkerDiscovered is the hook for "the player found the place your quest sent them to" — it fires for When Explored and Manual-class markers the first time their cell is explored, and never twice for the same marker.

Find a marker

MapMarker marker;
bool found = MiniAtlasApi.TryFindMarker("objective", out marker);

Finds the first registered marker of a category. The registry itself is public too (MiniAtlasRuntime.Registry), as is the active map (MiniAtlasRuntime.ActiveMap).
