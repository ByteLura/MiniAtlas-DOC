Sample Guide — The Atlas Tour

The Atlas Tour is the shipped sample: a capsule explores a walled ground while fog lifts around it. It is imported from the MiniAtlas Pro window (Open the Atlas Tour) or the menu (Tools > ByteLura > MiniAtlas Pro > Open the Atlas Tour), and its scene is generated by the shipped AtlasDemoSceneBuilder — the package ships scripts, never a blind-authored scene file, so every reference in the scene is real.

The ground

Bounds 96×64, fog on at cell size 2 (a 48×32 grid). The painted ground texture doubles as the map background — the same calibration your own world gets. Landmark blocks match the painted fields: the Mill Block, the Spring Block, the Storehouse Block.

Who is on it

  • Player — a capsule at the south-west, WASD or arrow keys (legacy Input), 12 units per second. Its marker is category player: rule Always, reveals fog in a 14-unit radius, heading tracked.
  • Wanderer One / Wanderer Two — NPC capsules drifting between random points. Category npc, rule When Visible: they appear on the map only while their fog cell is currently visible.
  • Old Mill (north-west) and Spring (south-east) — POI cubes, rule When Explored.
  • Hidden Cache (north edge) — a POI with rule Manual: hidden until revealed.
  • Tour Objective — a sphere in the far (north-east) corner, rule When Explored, set as the tracked objective when the tour starts.

The tour, step by step

  1. Press Play. The HUD line gives the instructions; the corner minimap (240×240, zoom 2, following the player) shows you, the fog around you, and the objective as an edge arrow — it is far outside the minimap's view.
  2. Walk. Fog lifts along your path in real time.
  3. Press M. The world map shows the explored shape of your walk — and nothing else. The Old Mill is still hidden: you have not been near it.
  4. Click the Reveal the hidden cache button (bottom-left). The cache marker appears on both maps — the Manual rule, exercised from the sample's own UI.
  5. Walk onto the objective. The HUD line changes to the completion line, and the cache is revealed if it was not already.

Reading it as code

The sample scripts (AtlasPlayerController, AtlasNpcWander, AtlasObjectiveDemo, AtlasSampleHud) use only the public API and reference the Runtime assembly only — they are the integration example. The director sets the objective through MiniAtlasApi and completes the tour on a plain distance check; nothing in the tour uses an internal member.
