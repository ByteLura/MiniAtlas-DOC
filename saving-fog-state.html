Saving Fog State

MiniAtlas Pro owns no save system and writes no files. The explored fog state is data, exposed through the API in two forms, for whatever save system your game already runs to store.

// Save — store the result wherever your save system stores data:
byte[] fogData = map.Fog.SaveExplored();
string fogText = map.Fog.SaveExploredBase64();   // text form

// Load — false means wrong shape or corrupt data; the grid is untouched:
bool ok     = map.Fog.TryLoadExplored(fogData);
bool okText = map.Fog.TryLoadExploredBase64(fogText);

What is saved

Explored state only — one byte per cell. Visibility is derived: after a load, the next fog tick (0.1 s) re-stamps visibility from your revealers' current positions. A malformed string or a wrong-shape payload returns false and changes nothing; loading never throws into your game loop.

The format

Format v1: a small header (magic MAF1, version byte, grid width and height, cell size) plus the explored bytes. A load whose grid shape or cell size differs from the current map's fog is refused cleanly. If you change fog resolution between game versions, rebuild the map with matching settings before loading old data — or treat the old fog as a fresh start; the refusal keeps either choice safe.

Round-trip guarantee

SaveExplored → a fresh grid of the same shape → TryLoadExplored reproduces the explored pattern cell for cell. The Base64 form round-trips identically. Both directions are covered by the shipped test suite and by the in-editor self-test inside Verify Install.
